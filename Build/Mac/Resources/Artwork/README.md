# LBMStudio app icon

Generated with the built-in image generation tool on 2026-10-07. The source PNG retains its original transparent background. macOS icon representations are resized with Apple's `sips`; no visual alterations are applied.

The project `Assets.xcassets/AppIcon.appiconset` is selected automatically by Unreal's modern macOS Xcode packaging. Its ten PNG representations cover 16, 32, 128, 256 and 512 points at 1x and 2x. `Info.Template.plist` needs no override.

## Artwork prompt

Use case: logo-brand.
Asset type: production macOS application icon for LBMStudio, an Unreal Engine computational fluid dynamics and lattice Boltzmann flow visualization tool.
Primary request: an exceptionally polished, recognizable app icon representing fluid flowing around a wing section.
Composition: square 1024x1024 canvas, single centered macOS rounded-square tile occupying about 88 percent of canvas, transparent outside the tile. Front-facing icon, no perspective mockup. A bold pale silver airfoil cross-section centered horizontally; rounded leading edge on the left and tapered trailing edge on the right. Five or six elegant thick cyan and turquoise flow ribbons curve smoothly above and below the airfoil, suggesting simulated fluid flow. A subtle restrained wake curl to the right. Clean readable silhouette even at 32 pixels.
Style: premium desktop engineering software icon, precise sculpted forms, restrained layered depth with softly beveled surfaces and crisp edges; sophisticated minimal visual design.
Palette: very dark midnight navy tile matching a navy CFD workspace, luminous cyan and teal streamlines, a pale ice-silver wing. Subtle light at upper left. Strong contrast with generous internal breathing room.
Constraints: no text, no letters, no numbers, no axes, no legend, no graph, no interface, no lattice grid, no intricate hairlines, no rainbow, no aircraft silhouette, no decorative particles, no watermark. Genuine transparent pixels outside the rounded square. One finished icon only.
